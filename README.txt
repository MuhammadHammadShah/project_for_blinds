BRAILLE MIRROR - LOCAL VERSION

1. Extract this ZIP first.
2. Double-click START.bat on Windows.
3. The website opens at http://localhost:8000 when Python 3 is installed.
4. Leave the terminal window open while using it. Ctrl+C stops the server.

NO INSTALLATION OPTION
Double-click index.html. Conversion and mirrored printing work offline,
without a server, internet connection, account, or additional dependencies.
START.bat also uses this option if Python is unavailable.

MAC / LINUX
Run: python3 server.py

PRINTING
Type English text, then click Print mirrored Braille.
Every complete line is flipped horizontally, including cell order.
Select 100% scale, A4 or Letter, and disable headers and footers.
Only Braille dots are printed. Physical printer output is not verified.
Ordinary printers create flat dots; raised Braille requires manual marking
or embossing.

SUPPORTED TEXT
Basic uncontracted English letters, capitals, digits, spaces, line breaks,
and the common punctuation listed on the page. Unsupported characters
are flagged. This is not a full professional Braille transcription engine.
All text processing takes place in your browser; nothing is uploaded.

FULL DOCUMENTS
Paste up to 50,000 characters. Enter starts a new line; two Enters leave a
blank line between paragraphs. Blank lines and indentation are preserved.
Text wraps at 28 Braille cells, preferring word boundaries. Words longer
than a line are split. Pages hold 23 lines and are shown separately in the
preview. Print uses the same page breaks and mirrors each line, retaining
top-to-bottom order. Page labels are preview-only and do not print.
Use A4 or Letter portrait, 100% scale, headers/footers off. Other paper sizes
or printer scaling can change pagination. This remains a basic converter,
not a professional long-form Braille transcription engine.
